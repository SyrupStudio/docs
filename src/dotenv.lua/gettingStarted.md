# Getting Started

## What is dotenv.lua
dotenv.lua is a minimal dotenv library for Lua 5.1+

SOURCE CODE: [Here](https://github.com/SyrupStudio/dotenv.lua/)

## From [LDE](https://lde.sh/)
1. Run 
```bash
lde add dotenv
```

2. Require it

```lua
require("dotenv")
```

## From source
1. Clone the repository
```bash
git clone https://github.com/SyrupStudio/dotenv.lua/
```

2. Open the folder of the newly cloned repo

3. Drop `dotenv.lua` into your project and require it

```lua
require("dotenv")
```
